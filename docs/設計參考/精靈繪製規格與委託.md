# OnPlay 怪物精靈 — 繪製規格與委託書

> 把這份文件整份交給負責繪製的 AI（或人）即可。畫完依「§7 回傳格式」給我一個 JSON，我就能直接匯入遊戲、跑驗證、出預覽、合併進 `main`。
> 搭配參考：怪物的「該有原型/戰鬥定位」見同資料夾 `怪物設計依據.md`。

---

## 1. 這是什麼
OnPlay 是純前端的放置型自動戰鬥遊戲，怪物精靈用**馬賽克點陣字串陣列**表示（不是圖片檔）。
每隻怪 = 一個「字串陣列」，每個字元 = 一格像素的顏色（取自固定調色盤），`.` = 透明。
引擎把這個格子放大繪製到畫面上。**你的產出就是這種字串陣列**，不是 PNG。

## 2. 精靈編碼格式（最重要）
- 一隻怪 = `["列1","列2",...]`，由上到下每列一個字串。
- 每個字元是**調色盤鍵**（見 §5），代表該格顏色。
- `.`（句點）或空格 = **透明**（不畫）。
- 各列**建議等寬**；若不等寬，較短的列右側自動補透明（引擎容許，但等寬最整齊）。
- 1 字元 = 1 像素格，遊戲會整體放大。

### 範例（一隻綠色史萊姆，10×8）
```
..GGGG..
.GGGGGG.
GGWGGWGG     ← W 是白色眼白
GGKGGKGG     ← K 是深色瞳孔
GGGGGGGG
GGGGGGGG
.DDDDDD.     ← D 深綠當底部陰影
..DDDD..
```
對應陣列：
```json
["..GGGG..", ".GGGGGG.", "GGWGGWGG", "GGKGGKGG", "GGGGGGGG", "GGGGGGGG", ".DDDDDD.", "..DDDD.."]
```

## 3. 繪製慣例（務必遵守）
1. **不要自己畫黑色外框**。引擎會**自動描邊**（在輪廓外緣補深色框）。你只要畫「實心的角色本體」，留白處用 `.`。
2. **面向右**畫（角色朝右）。戰鬥時引擎會自動左右翻面，所以朝右畫即可。
3. **底列貼地**：角色「腳/底部」要落在陣列的最後一列（角色是站在地上的，底部對齊地面）。腳下不要留整列空白。
4. **水平置中**：左右盡量對稱留白，角色會以中心對齊。
5. **剪影要清楚**：有些怪是「隱身」狀態時只會畫出**空心輪廓**，所以外型剪影本身要辨識度高。
6. **眼睛慣例**：白眼用 `W`，瞳孔用 `K` 或 `e`（深色），會讓怪更有神。
7. 顏色只能用 §5 調色盤裡的鍵；用到表外字元的格子會被當成沒有顏色而**不顯示**。

## 4. 建議尺寸（方形畫布；未來統一標準）
**概念**：每類用一個**固定方形畫布**，造型可比畫布小，但**置中＋底部貼地**畫在畫布內 → 尺寸統一又不強迫塞滿。引擎容忍不等寬列、自動置中。

| 類型 | 統一畫布(寬×高) | 可接受範圍 |
|---|---|---|
| 英雄 hero | **16 × 16** | 固定 |
| 寵物 pet | **14 × 14** | ≤14 |
| 小怪（small） | **14 × 14** | 10–14 |
| 魔王（boss） | **20 × 20** | 16–20 |
| 物品/素材 icon | **12 × 12** | 固定 |

（既有圖尺寸偏舊小、日後分批遷移；**新圖一律用上表方形畫布**。詳見 `美術知識庫.md`。）

## 4b. 可愛像素風格指南（畫風方向）
追求**乾淨、討喜、辨識度高**的可愛像素：① Q 版頭大身小；② 引擎自動描邊→**勿自畫黑框**；③ **高彩度強對比**，每隻 1–2 主色＋1 亮點；④ 每面只用**亮/中/陰影三階**；⑤ **大眼睛**（白 `W`＋深瞳 `K/e`）＋單格高光；⑥ **剪影優先**、配件決定身分。完整版見 `美術知識庫.md` §1。

## 7. 回傳格式（畫完這樣給我）
給我**一個 JSON**（存成檔案或直接貼上皆可），鍵用下面 §8 清單的 **怪物ID**：

```json
{
  "_meta": { "note": "OnPlay 怪物精靈", "by": "（誰畫的，可省）" },
  "_palette": { "3": "#a0e0ff" },
  "sprites": {
    "deer":   ["N.N....N.N", ".NhN..NhN.", "...（每列一字串，等寬）..."],
    "treant": ["...", "..."],
    "b_slime":["...", "..."]
  }
}
```
- `sprites`：**必填**。鍵 = 怪物 ID（見 §8），值 = 字串陣列。
- `_palette`：選填，只有要用「現有調色盤沒有的新顏色」時才加。
- 你可以**只畫一部分**（例如先交一個區），我會只匯入有給的那些，其餘維持原樣。
