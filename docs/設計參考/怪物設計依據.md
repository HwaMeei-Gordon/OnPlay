# 怪物設計依據（類型慣例對照）

本文件說明 `src/data.js` 之 `MONSTERS` 名冊**每隻小怪的設計參考來源**，確保各區怪物符合經典 RPG/JRPG 該生態區「該有」的原型，而非憑空想像。對照基準：D&D / Pathfinder 的「依地形分類怪物（monsters-by-terrain）」、Final Fantasy / Dragon Quest / Diablo / Castlevania 等 wiki 慣例。

> 設計通則（每區應齊備的槽位）：**坦克 + 快攻雜兵 + 遠程施法 + 飛行 + (召喚) + 區域 Boss**；異常狀態主題化。
> 沙盒網路僅放行 GitHub，無法抓外部參考圖；精靈一律沿用專案既有 `PALETTE` 手繪，造型依各區主題與下列原型設計。
