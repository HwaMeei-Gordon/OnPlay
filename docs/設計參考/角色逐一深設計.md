# 角色／怪物「逐一深設計」紀錄

> 做法（使用者指定）：**一次只深刻設計一個**角色或怪物，做完一個再下一個。
> 每個都先「查典型裝備 → 學參考遊戲的比例/服裝 → 訂設計規格 → 手刻精靈 → 校稿 → 注入」。
> 參考遊戲：Heroll、Idle Horizons（只學比例/服裝/上色語言，不複製圖檔）。
> 共用畫布：64×64、3/4 面右、step=1/4；引擎自動描邊＋程序化動畫（走/攻/傷/狀態）。

## 通用比例準則（從參考歸納）
- **矮壯 chunky ~2 頭高**（Heroll 風：**大頭、短粗身、厚手腳、大手大腳**）。＊先前一版做太瘦長(2.5–3頭)被退；定案＝矮壯。
- **小而銳利的眼**（2px 深窩＋1px 亮瞳＋眉影），大頭配小眼＝Heroll 看板感。
- **融入式肩**（不要圓球 pauldron）。
- **服裝看身份**：法系飄逸及地長袍；戰系護甲；平民布衣＋草鞋。
- **3–5 階明暗**、布料直向褶皺、抗鋸齒曲線（aadisc）。
- **武器握在手上**；近戰攻擊＝大幅前傾揮擊。
