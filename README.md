# 勇者放置記（Brave Idle）

一個可以在手機 Chrome 上直接遊玩的**放置（idle）遊戲**。馬賽克像素風格，勇者自動往前冒險、遇敵自動戰鬥；你負責透過**裝備**與**技能**讓勇者越來越強，一路挑戰越來越強的敵人與魔王。

進度自動儲存在**這台裝置的瀏覽器**（localStorage），關掉網頁再回來也會繼續，並有**離線收益**。

## 🎮 玩法

- 勇者固定在畫面左側自動前進，敵人從右方接近。
- 相遇後**自動互相攻擊**，無需手動操作。
- 擊殺敵人掉**金幣**並累積**經驗值**（自動升級，提升基礎能力）。
- 每關打倒一定數量的小怪後出現**魔王**，擊敗魔王即進入下一關。
- 關卡越高，敵人越強、金幣與經驗也越多。
- 勇者生命歸零會**從該關重新開始**（金幣、裝備、技能、等級都會保留）。

### 你能做的設定

- **裝備**：武器（攻擊）、防具（生命/防禦）、飾品（暴擊/攻速）。花金幣強化升級。
- **技能**：
  - 被動：強健體魄（生命）、精準打擊（暴擊）。
  - 主動（冷卻到自動施放）：火球術、治癒術、狂暴。
- 隊友 / 寵物系統：規劃中，之後版本推出。

## 🌐 線上遊玩

部署到 GitHub Pages 後，網址格式為：

```
https://<你的帳號>.github.io/<repo 名稱>/
```

用手機 Chrome 開啟即可遊玩，建議「加到主畫面」當作 App 使用。

## 🚀 部署（GitHub Pages）

本專案是**純靜態網站，無需建置**。倉庫已內含自動部署設定 `.github/workflows/pages.yml`。

1. 進到 GitHub repo → **Settings → Pages**。
2. **Build and deployment → Source** 選擇 **GitHub Actions**。
3. 把本分支的變更合併到 `main`，Actions 會自動部署，完成後在 Pages 設定頁可看到網址。

> 也可改用「Deploy from a branch → `main` / root」的方式，因為遊戲檔案都放在倉庫根目錄。

## 🧪 本機測試

由於使用傳統 `<script>` 載入，可直接用瀏覽器開 `index.html`；或啟動簡易伺服器：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

用瀏覽器開發者工具的「裝置模擬（直式手機）」檢視手機版面。

## 🗂️ 專案結構

```
index.html          頁面骨架（canvas + HUD + 分頁面板）
assets/style.css    手機優先、像素風樣式
src/data.js         常數、數值縮放、裝備/技能定義、像素點陣圖
src/save.js         localStorage 存讀檔 + 離線收益
src/render.js       Canvas 像素渲染
src/game.js         遊戲狀態、戰鬥、關卡進程、升級、結算
src/ui.js           DOM 介面（HUD / 裝備 / 技能 / 數據）
src/main.js         入口、主迴圈、自動存檔
```

## 💾 存檔說明

- 進度存在瀏覽器的 localStorage（key：`brave-idle-save-v1`）。
- **換手機、換瀏覽器或清除瀏覽資料會遺失存檔。**
- 在「更多」分頁可重置進度。
