# 勇者放置記（Brave Idle）

一個可在手機 Chrome 直接遊玩的**開箱放置 RPG**。馬賽克像素風格、多英雄隊伍自動冒險，你負責養成英雄、開箱抽裝、轉生變強，挑戰 1000 層、10 大區域、越來越強的敵人與魔王。

進度自動存在**這台裝置的瀏覽器**（localStorage），有**離線收益**。純靜態網頁、**無建置步驟**。

## 🎮 核心玩法

- 出戰隊伍（最多 4 名英雄）在畫面左側自動前進，敵人從右方接近、**自動戰鬥**。
- 每層清掉一波小怪後前進；**每 10 層出現魔王**（魔王與小怪造型依區域變化、後期同屏多隻）。
- 擊殺掉**金幣**、魔王掉**鑽石**；全隊陣亡會從該 10 層段起點重來（保留所有養成）。
- 每 100 層切換區域：草原→森林→沙漠→雪地→熔岩山→深海→天空之城→遺跡→魔王城→深層。

## 🧩 系統

- **多英雄養成**：每名英雄**獨立等級、獨立裝備、獨立技能**；可編組出戰隊伍。
- **裝備 + 開箱**：6 部位裝備、5 種稀有度（普通→傳說）、金幣/鑽石寶箱（×1/×10）、強化、分解、自動裝備。
- **屬性訓練**：10+ 種全隊永久加成（攻/血/防/暴擊/暴傷/攻速/吸血/閃避/尋金/經驗）。
- **才能天賦**：用才能點投資永久加成。
- **轉生 / 突破**：重置進度換靈魂，投入轉生天賦得永久全域倍率。
- **寵物**：出戰提供全隊加成、可升級。
- **商店**：招募英雄、買寵物、寶箱、每日特惠。
- **任務 / 成就 / 每日**：給鑽石與金幣獎勵。
- **三貨幣**：金幣 💰 / 鑽石 💎 / 靈魂 🔮。
- **便利**：戰鬥加速（1×/2×/4×）、離線收益、自動存檔、PWA 加到主畫面。

## 🚀 部署（GitHub Pages）

純靜態、無建置。倉庫內含 `.github/workflows/pages.yml` 自動部署。

1. repo **Settings → Pages → Source** 選 **GitHub Actions**（或 `main` / root 分支來源亦可）。
2. 合併到 `main` 後 Actions 自動部署。

## 🧪 本機測試

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

## 🗂️ 專案結構

```
index.html              骨架（canvas + HUD + 分頁 + modal）
assets/style.css        像素馬賽克風格、RWD、動畫
manifest.webmanifest    PWA
src/data.js             所有靜態設定與數值
src/sprites.js          英雄/敵人/魔王/寵物 點陣圖
src/systems.js          養成邏輯與存檔狀態（純運算）
src/save.js             存讀檔 + v1→v2 遷移 + 離線收益
src/render.js           Canvas 4 層景深渲染
src/game.js             戰鬥引擎（隊伍 vs 多敵人波次）
src/ui.js               DOM 介面（英雄/背包/開箱/商店/寵物/訓練/天賦/轉生/任務）
src/main.js             入口、主迴圈、自動存檔
```

## 💾 存檔

- localStorage key：`brave-idle-save-v2`（會自動沿用舊版 `v1` 的金幣與最高關卡）。
- 換裝置或清除瀏覽資料會遺失存檔。可在「設定」重置進度。
